What to try

  1. Ask a question. The first provider that serves the chosen model answers it; the line beside the model picker shows the order.
  2. Simulate an outage on that provider, then send about five requests. The first few take ~3.5 s longer while the gateway retries it, then the circuit opens and the fallback becomes instant. The Operations dashboard shows the circuit and the fallbacks.
  3. Wait for the outage to end. After the cooldown, the next request tests the provider again and the circuit closes.
  4. Send 25 quick requests. The team allows a set number per minute, so the rest are rejected with 429. The limit is shared by everyone on this page.
  5. Switch to the policy team and try the social security number prompt. It is blocked with 400 before any provider sees it.
